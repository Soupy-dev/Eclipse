# Eclipse

Eclipse was a free, open source iOS media hub application. There were also plans to expand to Windows, tvOS, and macOS, with a lot of work completed on some of these platforms. However, none of these versions were publicly released or fully completed.

At the time of writing, Eclipse had accumulated around 1,900 GitHub downloads and 126 stars. Across TestFlight and the App Store, the app reached roughly 7,000 users in total. It never generated much money, but making money was never the goal.

Development began in December 2025. The project had a rocky start, including some controversy before its initial release that was my responsibility (again, sorry, Cranci). Thankfully, this was eventually resolved privately and on peaceful terms.

Today is October 28, 2026, and **Eclipse is officially ending public development.**

While the application will no longer receive official public updates or support, the repository will remain available as a record of the project and the work that went into it.

Thank you to everyone who used Eclipse, contributed to it, reported bugs, or supported its development along the way.
